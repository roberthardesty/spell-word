# Model staging directory

This directory holds the trained TFLite model that gets flashed to the
`model` partition (subtype 0x80, label `model`, 256 KB) before the
recognizer can classify letters. The blob itself is `.gitignore`d — it's
generated by the upstream model-training project and is not source.

## Expected file

| Path | Format | Size | Input | Output |
|---|---|---|---|---|
| `models/model.tflite` | TFLite flatbuffer (int8 quantized DS-CNN) | ~51 KB | `[1, 79, 20, 3]` (MFCC + Δ + ΔΔ, NHWC) | 26-class softmax (or logits — firmware applies softmax if input is out of `[0, 1]`) |

Mismatched input shape, output dim, or schema version will fail
`AllocateTensors()` or the post-`Invoke()` sanity check at boot — see the
`recognizer:` log lines.

## Validate before flashing

```bash
python3 -c "
import tensorflow as tf
i = tf.lite.Interpreter('models/model.tflite')
i.allocate_tensors()
print('input :', i.get_input_details()[0]['shape'], i.get_input_details()[0]['dtype'])
print('output:', i.get_output_details()[0]['shape'], i.get_output_details()[0]['dtype'])
"
```

Expected:
```
input : [ 1 79 20  3] <class 'numpy.int8'>
output: [ 1 26] <class 'numpy.int8'>
```

## Flash to the device

```bash
. ~/esp/esp-idf/export.sh
parttool.py --port /dev/cu.usbmodem101 \
    write_partition --partition-name model --input models/model.tflite
```

After flashing, boot the device — the `recognizer:` log line should
change from `model partition is empty (erased) — awaiting OTA` to
`model loaded from partition (262144 B)` followed by
`interpreter ready — arena used N / 262144 B`.

The `N` figure is what drives the arena-size tightening on Vikunja #39:
once measured, `SPELL_TENSOR_ARENA_SIZE` (in
`components/spell_common/include/spell_config.h`) can be dropped to
`≤ 1.2 × N`.
